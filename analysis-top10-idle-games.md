# Разбор топ-10 idle/incremental игр и рекомендации для «Микроволнового монастыря»

Дата: 2026-09-17. Источники: агрегированные рейтинги 2025–2026 (GamingScan, Mr.Mine Blog, Enjoy4fun, Life Guide, Clicker Heroes Blog). Топ-10 — консенсус списков популярности и «вечных» хитов жанра.

## 1. Топ-10 игр: что делает каждая и какие механики отвечают за её успех

### 1. Cookie Clicker (Orteil, 2013) — родоначальник жанра
- **Ядро**: клик → покупка зданий (курсоры, бабушки, фабрики, порталы, храмы времени) → экспоненциальные цены → рост дохода.
- **Ключевые механики**:
  - **«Золотые куки»** — случайно появляющиеся бонусы: Frenzy (×7 к производству на короткое время), комбо с активными таймингами. Случайные ивенты, за которыми следишь, превращают пассивный процесс в активную игру.
  - **Престиж (Ascension → Heavenly Chips)** — сброс за постоянные множители; каждый цикл быстрее предыдущего.
  - **Деревья апгрейдов по типам зданий** — каждое здание имеет собственную линейку из десятков апгрейдов (×2, особые свойства), а не один общий множитель.
  - **Мини-игры** (Сад/пасека и др.) — отдельные под-системы со стратегией.
  - **Юмор и тёмные откровения в описаниях** — придают характер.
- **Урок**: отдельные линейки апгрейдов + случайные ивенты + престиж = жанровый стандарт долгоживущей игры.

### 2. AdVenture Capitalist (Hyper Hippo, 2014) — тайкун для массовой аудитории
- **Ядро**: бизнесы, которые «кликаешь для старта», дальше работают сами; покупка апгрейдов, умножителей «за X».
- **Ключевые механики**:
  - **Менеджеры-автоматизаторы** — покупка NPC, который автоматически перезапускает производство (тут же ваша тема «роботы-поливальщики»!).
  - **Престиж через «ангелов-инвесторов»** — сброс даёт ангелов, каждый = постоянный +% дохода; «забрать ангелов / продолжить» — постоянное стратегическое решение.
  - **Мульпликаторы x3, x10, x50 за единовременную оплату** — «валютная» трата прогресса.
  - **Ивенты и сезонные механики** — ограниченные по времени режимы.
- **Урок**: роль персонажей-автоматизаторов и «решения о престиже сейчас или позже» — сильнейшие драйверы возвратов.

### 3. Clicker Heroes (Playsaurus, 2014) — кликер-RPG
- **Ядро**: тап по монстрам → золото → наём героев (десятки, у каждого своя линейка апгрейдов) → зоны → боссы → **Ascension** → **Transcension** (престиж над престижем).
- **Ключевые механики**:
  - **Двухслойный престиж**: Ascend (Hero Souls) и Transcend (Ancient Souls + героические души героев).
  - **Древние (Ancients)** — боги, которых покупаешь за престиж-валюту; каждый меняет правила (крит, золото с боссов, оффлайн-эффективность) → билды.
  - **Автопрогресс + клик-стиль** две валидные стратегии одновременно.
- **Урок**: слои престижа поверх друг друга создают «эндгейм» на месяцы.

### 4. Realm Grinder (Divine Games, 2015) — idle-стратегия
- **Ядро**: королевство, фракции (феи, эльфы, демоны, гоблины, друиды, лица...), у каждой фракции — своя валюта, здания, заклинания.
- **Ключевые механики**:
  - **Фракции и их уникальные бонусы** — выбор «пути» меняет всю экономику.
  - **Заклинания (активные кнопки с кулдауном)** — короткие мощные эффекты: удвоение, автоклик, бонус по времени игры.
  - **Исследования и кастомизация королевства** — слоты под разные механики.
  - **Глубокий престиж (Reincarnation)** — десятки циклов.
- **Урок**: «выбор фракции/школы» = простой способ дать реиграбельность одному клик-циклу.

### 5. Melvor Idle (Malcs, 2020) — RuneScape целиком в idle
- **Ядро**: не цифры ради цифр, а **древо навыков** (добыча, кузнечное дело, магия, бой с монстрами) — навыки тратят ресурсы друг друга.
- **Ключевые механики**:
  - **Много ресурсов, связанных производственными цепочками** — руда → слиток → меч.
  - **Система предметов, банк, боёвка со стихиями.**
  - **Мастерство навыков (mastery)** — чем дольше занимаешься навыком, тем выше пассивный уровень мастерства.
- **Урок**: цепочки ресурсов превращают простой прирост в «экономику».

### 6. NGU Idle (Somethingggg, 2017) — комедийная глубина
- **Ядро**: тысячи взаимосвязанных систем, абсурдный юмор, 10-нотация чисел.
- **Ключевые механики**:
  - **Множество одновременных «баров» прогресса** (энергия, магия, приключения, борода, NGU-тренировки) — игрок управляет распределением внимания.
  - **Бесконечные слои престижа** (Rebirth).
  - **Коллекции (MacGuffins, квестовые предметы)** с перманентными бонусами.
- **Урок**: «несколько параллельных систем прогресса» держат ветеранов; юмор держит всех.

### 7. Antimatter Dimensions (Hevipelle) — чистый математический инкрементал
- **Ядро**: вам всё время «не хватает порядка величины» — баланс держится на осмысленных логарифмических скачках.
- **Ключевые механики**:
  - **Галактики: Антиматерия → Бесконечность → Этерность** — престиж, который каждый раз *меняет правила игры*, а не просто даёт +%.
  - **Автоматизация как награда** — игрок постепенно «программирует» автопокупки, авто-престиж, авто-исследования.
  - **Исследования (challenge-условия)** — модификаторы правил за бонусы.
- **Урок**: престиж, меняющий правила + автоматизация как контент — эталон глубины для хардкорной аудитории.

### 8. Tap Titans 2 (Game Hive, 2016) — мобильный idle-RPG хит
- **Ядро**: тап по титанам, герои-напарники, артефакты, кланы, рейды.
- **Ключевые механики**:
  - **Артефакты за престиж-валюту (relics)** — случайный пул с усилением, этапы «салята».
  - **Кланы и кооперативные рейды** — социальный слой.
  - **Питомцы, сеты снаряжения, скиллы с кулдаунами.**
  - **Сезонные ивенты и турниры.**
- **Урок**: коллекционные престиж-бонусы + социальные цели удерживают мобильную аудиторию.

### 9. Idle Miner Tycoon (Kolibri, 2016) — самый скачиваемый idle-тайкун
- **Ядро**: шахта → элеваторы → склад → менеджеры, множество шахт, престиж шахт.
- **Ключевые механики**:
  - **Менеджеры с ролями** (автозапуск, скорость, прибыль) — отдельная мета-игра «собери лучший состав».
  - **Престиж отдельных узлов** — можно сбросить одну шахту, не всё.
  - **Ивенты-шахты и сезонный контент.**
- **Урок**: «менеджеры» как коллекция — простая и очень sticky-мета.

### 10. Egg Inc. (Auxbrain, 2016) — расслабленная глубина
- **Ядро**: курицы → яйца → фермы, **исследования (Epic Research)** на души, **престиж-яйца**.
- **Ключевые механики**:
  - **Исследования двух уровней**: обычные (перебалансируются каждый цикл) и «эпические» (постоянные, за редкую валюту).
  - **Престиж-яйца (Soul Eggs) дают % бонуса** — чистый накопительный слой.
  - **Контракты/кооперативы** — общие цели с другими игроками.
- **Урок**: разделение «циклических» и «постоянных» улучшений — понятный и честный престиж.

**Частые почётные упоминания в рейтингах**: Leaf Blower Revolution, Trimps, IdleOn, Idle Champions, AFK Arena, Universal Paperclips, A Dark Room — подтверждают те же закономерности.

## 2. Что общего у всех хитов (выжимка закономерностей)

1. **Престиж почти у всех** — не опция, а стандарт жанра. Причём лучшие (Clicker Heroes, Antimatter Dimensions) делают **слои престижа**, где новый слой меняет правила, а не просто даёт множитель.
2. **Случайные события в активной игре** (золотые куки Cookie Clicker) — превращают «смотреть на числа» в мини-игру внимания.
3. **Автоматизация как прогрессия**: AdVenture Capitalist, Idle Miner, Antimatter Dimensions — автоматизация покупается/разблокируется и сама становится контентом. Ваша игра это уже интуитивно чувствует (роботы-поливальщики в ТЗ).
4. **Отдельные линейки/древа апгрейдов**, а не один множитель: у каждого «здания»/героя свои апгрейды, особые свойства, синергии.
5. **Вторичные системы сверх ядра**: заклинания (Realm Grinder), навыки (Tap Titans 2), мини-игры (Cookie Clicker), питомцы/артефакты.
6. **Цели между сессиями**: достижения, коллекции, ивенты, сезоны — причины вернуться завтра.
7. **Горизонт прогнозируемости**: игрок всегда видит «следующую цель» — стоимость следующей покупки, следующий порог престижа, следующую фракцию.
8. **Характер и юмор** в текстах — дёшево в производстве, сильно в удержании (NGU Idle, Cookie Clicker).
9. **Оффлайн-прогресс** — есть у всех; лучшие делают возвращение «торжеством» (таст-экран «вот сколько вы заработали»). У вас уже реализован тост.
10. **Числа растут на порядки** — смена нотации (K→M→B→T→aa/ab) как ощущение власти. У вас `fmt()` уже это делает.

## 3. Привязка к «Микроволновому монастырю»: что и в каком порядке внедрять

Текущее состояние: 1 валюта (споры), 3 апгрейда (auto/click/mult), экспоненциальные цены, оффлайн-доход, x10-покупки. Это солидный скелет, равный Cookie Clicker 2013 года. Ниже — приоритетный бэклог, от дешёвого к дорогому.

### Фаза 1. Квартал «удержание первых сессий» (1–2 недели работы)
1. **Достижения (achievements)** — 15–25 штук: первые 10 колоний, первое удобрение, 1K кликов, доход 100/сек, 8 часов оффлайна. Пока без бонусов, потом с +1–3% к доходу за каждое — «лента целей».
2. **Случайные события «радиационные выбросы»** — аналог золотых куков, 100% в тему сеттинга: редко появляется светящийся гриб-мутант на экране; клик = Frenzy ×5–×7 на 30–60 сек, или «дождь спор» (+N спор сразу). Это оживит активную игру без новых систем.
3. **Милстоуны-апгрейды**: при кратных уровнях (25/50/100...) каждого апгрейда — разовые бусты «Споровая колония ×2», «Секатор критует (5% шанс ×10)». Даёт «прыжки» прогресса, любимые в жанре.
4. **Тексты с характером** — у каждого апгрейда и события описание в стиле «Советский биологический отчёт» с сухим юмором.

### Фаза 2. Квартал «глубина» (месяц)
5. **Престиж «Карантин»**: сброс спор/апгрейдов за **Споры-исследования** — постоянную валюту. Каждая = +5–10% к базовому доходу навсегда. Порог: когда игрок впервые достигает ~1e6 всего спор. Сразу решается проблема «всё куплено».
6. **Второй ресурс «Субстрат»** (питательная среда): колонии тратят субстрат вместо спор с некоторого уровня; субстрат производится «Компостером» (новая автолиния). Это первый шаг к цепочке Melvor: споры → субстрат → улучшенные колонии.
7. **Активные скиллы с кулдауном** (Realm Grinder): «Ирригация» (×3 к колониям 60 сек, CD 10 мин), «Люминесценция» (автоклик 15 сек), «Дезактивация» (следующая покупка −50%). Кнопки над грибом.
8. **Менеджеры-автоматизаторы** (AdVenture Capitalist/Idle Miner): NPC «Робот-поливальщик Иван» автоматически покупает N колоний в секунду, пока хватает спор — покупается один раз, за большую сумму. Дальше — рой роботов с ролями (скорость/скидки/крит закупки).

### Фаза 3. Квартал «долгоживущая игра» (2–3 месяца)
9. **Слой престижа над престижем**: после N карантинов открывается «Мутация штамма» — выбор одной из 3–5 «школ мутантов» (фракции Realm Grinder): Некроз (бонус к клику, кровавые споры), Флуоресценция (бонус к пассиву, события чаще), Мицелий (бонус к субстрату и цепочкам). Смена школ = частичный сброс. Даёт реиграбельность без нового контента.
10. **Коллекция «Гербарий»** — 20–30 редких грибов, падающих при событиях/достижениях; каждый даёт уникальный мелкий бонус; визуально заполняется полка в НИИ.
11. **Челленджи** (Antimatter Dimensions): «Цикл без удобрений», «Цикл только кликов» — за постоянные бонусы.
12. **Автоматизация как награда**: за споры-исследования — «протоколы» (автопокупка самого выгодного апгрейда, автопрестиж по условию, автоактивация скиллов).
13. **Сезонные ивенты** (если будет сервер/обновления): «Чернобыльская весна» — недельный режим с множителями и лидербордом (или оффлайн-целями).

### Фаза 4. Полировка
14. Мини-игра «Грибной сад» (Cookie Clicker) — сетка с мутациями: посадить образцы, скрещивать, получать постоянные бонусы. Можно сделать бесконечной метой.
15. Оптимизация нотации чисел (aa/ab за Qi), графики прогресса, статистика по циклам.

## 5. Главный принцип, вытекающий из анализа

У всех десяти хитов **ядро клик-экономики одинаково просто** (у вас уже есть), а разница — в слоях вокруг: престиж, случайные события, автоматизация, коллекции, ивенты. Поэтому стратегия развития «Микроволнового монастыря» — не усложнять формулу дохода, а **строить слои меты**. Приоритет: достижения + радиационные выбросы + милстоуны (быстрый выигрыш), затем «Карантин»-престиж и роботы-автоматизаторы (ядро удержания), затем мутации-фракции и слои престижа (долгоживущая игра).
